# Minimal Light — Hugo adaptation

This theme adapts Yaoyao Liu's [Minimal Light](https://github.com/yaoyao-liu/minimal-light)
to Hugo. Upstream revision: `1ea07f39518ac44644406380c83da6f89037c4fc`.

`assets/css/minimal-light.css` is the unchanged upstream compiled stylesheet.
Layouts are translated from Liquid to Hugo templates. Chinese typography,
navigation, awards and print styles are in `assets/css/resume.css`.
System fonts replace external font downloads. No demo images or analytics are used.
